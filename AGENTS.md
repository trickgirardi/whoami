## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## ALWAYS

- Always use the **Caveman skill** when it is available.
- Always ask for confirmation before making decisions that affect architecture, dependencies, data models, project structure, conventions, or implementation approach.
- When multiple valid approaches exist, briefly present the options, trade-offs, and your recommendation, then wait for approval before proceeding.
- Do not make assumptions about product or business requirements. Ask before choosing behavior that is not explicitly defined.
